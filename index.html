Privacidad y uso

  • Lo que escribes (tus respuestas) se guarda solo en el navegador de este dispositivo: no se envía a ningún servidor y no hay cuentas ni cookies.
  • Cuando descargas el PDF de un ejercicio, se avisa al profesor de que lo has hecho: se envían tu nombre, tus apellidos, tu ciclo, el ejercicio y la fecha. Solo el profesor puede verlo.
  • Para saber cuánto se usa cada ejercicio contamos las visitas de forma anónima: tu navegador guarda un número aleatorio y solo se registra qué página se abre y qué día. No se guarda tu nombre, tus respuestas ni tu dirección IP.
  • Si cambias de ordenador o borras los datos del navegador, el borrador no estará. Descarga el PDF para no perder tu trabajo.
  • El trabajo debe ser tuyo: el texto no se puede pegar y el uso de inteligencia artificial debe declararse.
  • Probado en navegadores de escritorio actuales (Chrome, Edge). En tablets y móviles puede comportarse distinto.
